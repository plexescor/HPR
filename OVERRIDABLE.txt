The following functions in HPR are currently overridable by Lua extensions via the `HPR.overrides` table:

1. validateAndUpdateWindow_Cross
   - Description: Normalizes and filters window titles before they are processed by the engine or stored in the database.
   - C++ Call Site: src/window/validateAndUpdateWindow.cpp
   - Lua Override Key: HPR.overrides.validateAndUpdateWindow_Cross

2. showNotification
   - Description: Handles drawing system desktop notifications via DBus (Linux) or WinToast (Windows).
   - C++ Call Site: src/window/windowUtilities.cpp
   - Lua Override Key: HPR.overrides.showNotification

3. getAlias
   - Description: Retrieves the alias for a given application's raw name.
   - C++ Call Site: src/miscellaneous/aliasManager.cpp
   - Lua Override Key: HPR.overrides.getAlias

4. getAlias_Tab
   - Description: Retrieves the alias for a given browser tab's raw title.
   - C++ Call Site: src/miscellaneous/aliasManager.cpp
   - Lua Override Key: HPR.overrides.getAlias_Tab

5. getAlias_Project
   - Description: Retrieves the alias for a given project directory's raw name.
   - C++ Call Site: src/miscellaneous/aliasManager.cpp
   - Lua Override Key: HPR.overrides.getAlias_Project

6. dbQuery
   - Description: Runs a SQL SELECT query with dynamic string parameters. Intercepts database queries.
   - C++ Call Site: src/database/databaseManager.cpp
   - Lua Override Key: HPR.overrides.dbQuery

7. dbExecute
   - Description: Runs write SQL commands (INSERT, UPDATE, DELETE, etc.) with dynamic string parameters. Intercepts database writes.
   - C++ Call Site: src/database/databaseManager.cpp
   - Lua Override Key: HPR.overrides.dbExecute

8. getCurrentWindow_E
   - Description: Returns the name/app of the active window. Allows spoofing active app state.
   - C++ Call Site: src/extension/window_E.cpp
   - Lua Override Key: HPR.overrides.getCurrentWindow_E

9. getCurrentTitle_E
   - Description: Returns the title of the active window. Allows spoofing active tab/title state.
   - C++ Call Site: src/extension/window_E.cpp
   - Lua Override Key: HPR.overrides.getCurrentTitle_E

10. getReverseAlias
    - Description: Resolves an alias back to its raw application name.

    - Lua Override Key: HPR.overrides.getReverseAlias

11. getReverseAlias_Tab
    - Description: Resolves a tab alias back to its raw tab title.
    - C++ Call Site: src/miscellaneous/aliasManager.cpp
    - Lua Override Key: HPR.overrides.getReverseAlias_Tab

12. getReverseAlias_Project

    - Lua Override Key: HPR.overrides.getReverseAlias_Project

14. getLiveTimeLogPerTab_E
