# Code of Conduct

## The Short Version

Be a decent human. Disagree on code all you want, get frustrated, say this PR is shit — that's fine. What's not fine is making it personal or making someone feel unwelcome.

## What's Fine

- Telling someone their approach is wrong and why
- Saying a PR is badly written or needs work
- Disagreeing hard on technical decisions
- Cursing when you're frustrated ("this code is a mess", "what the fuck is this")
- Honest, blunt feedback

## What's Not Fine

- Personal attacks — attacking the person, not the code
- Harassment of any kind
- Racist, sexist, homophobic, or any other discriminatory shit
- Doxxing — posting someone's private info
- Sexual content or language
- Being a dick to someone specifically because of who they are

There's a difference between "this PR is garbage and here's why" and "you're an idiot". One is fine. The other isn't.

## Where This Applies

Anywhere HPR has a community presence: GitHub issues, PRs, discussions, Discord, anywhere else people interact around HPR.

## Reporting

## Consequences

Depends on how bad it is. Ranges from a warning to getting permanently removed from the community. I decide.
